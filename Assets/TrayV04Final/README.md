## Состояния и файлы

| Состояние | Верх / низ | Основные ICO |
| --- | --- | --- |
| Не подключён / неизвестно | Серый / серый | `ICO/disconnected.ico` |
| Подключается / восстанавливает связь | Оранжевый / зелёный, меняются местами | `ICO/connecting-a.ico`, `connecting-b.ico` |
| Авторизация | Оранжевый / серый, меняются местами | `ICO/authorization-a.ico`, `authorization-b.ico` |
| Готов к работе | Оранжевый / зелёный постоянно | `ICO/ready.ico` |
| Выполняет команду | Оранжевый / пульсирующий фиолетовый | `ICO/working-static.ico`, `working-01.ico`…`working-35.ico` |
| Ошибка подключения | Красный / красный | `ICO/connection-error.ico` |

Названия имеют значение для интеграции. В прежнем **Просмотре 03** `auth-a/b` показывали оранжевый/зелёный, а `connecting-a/b` — оранжевый/серый. В финальном комплекте соответствия намеренно обратные. Использовать именно этот комплект и `manifest.json`; старые просмотры — история.

## Передача Programmer

Назначить текущий значок по `manifest.json`. `Connecting` и `Reconnecting` используют анимацию `connecting`; `AuthPending` — `authorization`; `Fault` — полностью красный значок. Выполнение показывать только при `Ready` и `toolActivity=working`. `hold` возвращает обычную готовность. Ошибки отдельных команд не меняют значок. При недостоверном состоянии использовать серый; закрытие окна не означает выход Host, полный выход убирает значок.

Анимацию выполняет приложение сменой `NotifyIcon.Icon`; **ICO сам не проигрывается**. Предзагрузить нужные для текущего DPI иконки, использовать последовательность из manifest, не загружать файлы заново на каждом тике. При смене состояния остановить предыдущую последовательность и перейти к новому состоянию. Tooltip описывает состояние, не кадр; освобождать принадлежащие приложению ресурсы при завершении.

Чередование — цикл 1600 мс, смена половинок каждые 800 мс, плавный переход 160 мс. Последовательности учитывают повторяющиеся неподвижные кадры. Пульсация нижней фиолетовой половинки — 1800 мс, 36 кадров по 50 мс, непрозрачность 45–100%, кривая ease-in-out. При отключённых анимациях использовать `staticFallback`; подпись различает подключение и готовность, которые в неподвижном варианте имеют одинаковые цвета.

Графика принята, комплект проверен отдельно. **Интеграция в работающую программу не выполнена**: Programmer должен проверить реальные переходы, DPI, доступность режима без движения и освобождение ресурсов. Живой Remote, установленное приложение и процессы не изменялись.
