Remote Desktop Commander v1.5.3

УСТАНОВКА
1. Запустите "Remote Desktop Commander Setup v1.5.3.exe".
2. Установщик обновит предыдущую версию на месте.
3. После установки используйте ярлык "Remote Desktop Commander" на рабочем столе.
4. Установщик сам обновляет иконку ярлыка и сбрасывает кэш значков Windows.

ТРЕБОВАНИЯ
- Windows
- Node.js 18 или новее
- Компьютер и ChatGPT должны быть авторизованы в одном и том же аккаунте Desktop Commander.

ВЕРСИЯ 1.5.3
- Интерфейс разделён на две независимые текстовые области:
  верхний Header содержит стартовый блок, состояние подключения, устройство и команды;
  нижний Activity содержит только последние шесть remote-событий.
- Обновления Activity больше не перерисовывают Header, поэтому стартовый блок остаётся визуально стабильным.
- Header использует перенос строк без горизонтальной прокрутки и отдельный вертикальный кастомный scrollbar.
- Вертикальные scrollbar'ы масштабируют thumb по реальному числу визуальных строк и числу строк, помещающихся в окне.
- Вертикальный drag выполняется через построчную прокрутку RichEdit; нижняя граница трека принудительно ведёт к реальному дну текста.
- Activity хранит шесть последних событий вместо трёх.
- Отдельная галочка "Автопрокрутка" удалена.
- Live-follow работает автоматически:
  когда Activity находится внизу, новые события продолжают вести вниз;
  если пользователь вручную прокрутил вверх, текущая позиция сохраняется.
- При запуске Activity открывается на минимальной высоте, поэтому Header получает максимально возможную высоту.
- Header и Activity имеют одинаковый предпочтительный минимум 125 px.
- Разделитель между Header и Activity можно перетаскивать как за нижний grip, так и непосредственно за саму полосу.
- Разделительная зона визуально обрамлена фиолетовыми линиями сверху и снизу.
- Верхняя панель управления отделена от Header дополнительной тонкой фиолетовой линией.
- Базовый размер окна — 1074x900.
- Ширина окна фиксирована; пользователь может изменять высоту системной рамкой Windows.
- На мониторе с меньшей рабочей областью стартовый размер автоматически вписывается в Screen.WorkingArea.
- Минимальная высота формы рассчитывается так, чтобы обе текстовые области сохраняли допустимую высоту; на очень низком экране пределы адаптируются симметрично.
- При нажатии "Завершить" viewport Activity фиксируется до последнего события остановки.
- Служебное выделение RichTextBox скрывается во время цветового форматирования.
- Header сохраняет смысловую подсветку:
  Online — зелёный;
  Offline — красный;
  email, Device ID, Device Name и UUID устройства — голубой;
  Help: и Log out: остаются нейтральными, жёлтым выделяются только команды.
- Нижняя информационная строка показывает аккаунт, PID, время работы и версию без отдельного элемента автопрокрутки.
- Иконка приложения сохраняет фирменную палитру: D — фиолетовая, C — оранжевая.
- DesktopCommander.ico содержит отдельные размеры 16, 20, 24, 32, 40, 48, 64, 96, 128 и 256 px.
- Установщик создаёт versioned-копию DesktopCommander-v1.5.3.ico и переназначает существующий ярлык на неё, чтобы Windows не показывала старую иконку из кэша.
- Полный remote-session.log по-прежнему сохраняется на диске без урезания.

Полный журнал:
%LOCALAPPDATA%\RemoteDesktopCommanderLauncher\remote-session.log
