# RDC Relay — пользовательская тестовая сборка P3

Это отдельная демонстрация, не установленный RDC Relay. Значок — информационный, отличающийся от настоящего. Настоящий Desktop Commander Remote не запускается, не переподключается и не останавливается. Данные терминала, журнала, аккаунта и Remote синтетические.

## Запуск без редактирования команд

Откройте эту папку в проводнике STARMER, Windows PowerShell 5.1 уже входит в Windows.

1. Дважды щёлкните «Запустить RDC Relay DEMO.cmd». Откроется отдельное окно «RDC Relay — демонстрация», а в системном трее появится значок «RDC Relay DEMO». Он может быть среди скрытых значков. После запуска консоль можно закрыть — Host продолжит работу.
2. Проверьте заголовок, статус, «Аккаунт ▾», неактивную кнопку «Запустить», справку «?», терминал, журнал, нижнюю строку статуса и оригинальный баннер. Меню «Аккаунт ▾» использует названия действующего приложения: «Сменить аккаунт…», «Переподключить», «Управление устройствами…», «Подтвердить новое устройство…». Они отключены, поскольку настоящий аккаунт не используется.
3. Нажмите X — завершается процесс GUI. Дважды щёлкните значок «RDC Relay DEMO» в трее: откроется новый GUI. Повторный двойной щелчок при открытом GUI не создаёт второй GUI.
4. Проверка обновления: закройте GUI A, дважды щёлкните «GUI версия B.cmd». Изменяется только временная копия DemoGui.ps1 данного тестового экземпляра. Дважды щёлкните значок трея: откроется GUI B с новым PID. Host PID и фиктивный идентификатор Remote должны остаться прежними. В B нижняя полоска золотая вместо оранжевой.
5. Правый щелчок по тестовому значку открывает меню «Открыть RDC Relay», «Статус: демонстрация», «Завершить тестовую сборку…». Завершение требует подтверждения и через тестовый IPC просит только свой GUI выйти. Host завершится после своего GUI. Принудительных taskkill и Stop-Process нет.
6. После завершения дважды щёлкните «Проверить завершение и очистить.cmd». Скрипт проверяет процессы текущего тестового Host/GUI и удаляет только завершённый GUID-каталог P3. Если процессы ещё живы, он откажется удалять файлы.

## Безопасность и точность интерфейса

- Только Windows PowerShell 5.1 в текущем интерактивном сеансе STARMER, без повышения прав. Ключ ExecutionPolicy Bypass применяется только к запускаемому процессу, глобальную политику не меняет.
- Производственный Source/remote-window.ps1 служит исключительно визуальным ориентиром и никогда не выполняется. Отдельная копия публичного rdc-banner.png из дизайн-материалов содержится в тестовом комплекте.
- Геометрия основана на реальном окне 1074×900: верхняя панель 78 px, нижняя 38 px, разделитель 7 px, журнал 125 px. Цвета #1D2024, #121417, #7B5FA2, #BF7643, #EBB857; Segoe UI/Consolas, WinForms DPI scaling.
- Вся функциональность реального Remote и аккаунта отключена. Это не доказательство успешного подключения.
- Исторические два RDC-P1 и один RDC-P2 каталог со статусом NOT CLEAN не изменяются.
- Физические X, двойной щелчок, меню, внешний вид, DPI и доступность требуют непосредственной пользовательской проверки. Автотест не управляет физической мышью.

## Автотест для Reviewer

В этой папке:

    powershell.exe -NoProfile -NonInteractive -STA -ExecutionPolicy Bypass -File Test-P3VisibleWindow.ps1

Проверяет настоящие HWND и отдельные GUI-процессы, переход A→B, 10 циклов, отсутствие второго GUI и безопасное завершение только тестового Host. Использует нативный WM_CLOSE к подтверждённому собственному окну и TEST_* IPC, а не физический щелчок.

Рядом с папкой P3 находится отдельный архив RDCRelay-P3-UserDemo.zip. Распакуйте и запустите .cmd из распакованного каталога P3 — установка не требуется.
