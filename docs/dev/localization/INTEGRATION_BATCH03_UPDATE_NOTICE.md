# RDC Relay 1.6.0 — локализация индикатора обновлений (партия 03)

**Статус: исходники и изолированные тесты, не релизная сборка.** Продолжение `INTEGRATION_BATCH02_JOURNAL_NOTICES.md`, 2026-11-18, роль Programmer 5.

## Граница изменения

- Только Owner GUI: `Source/update-notice.ps1` переводит подсказку неактивного индикатора и доступное имя/подсказку активного объявления о **проверенной опубликованной стабильной версии**. Новый `Refresh-RdcOwnerUpdateNoticeLanguage` вызывается без повторного `Begin` при выборе языка из GUI или трея. Подписи формируются из готовых `ru-RU/en-US` ресурсов по трём семантическим ключам. `{version}` подставляется только из уже принятого `OfferedVersion`; значением нельзя управлять через перевод.
- Отдельная проверка `Get-RdcOwnerNoticeText` возвращает оригинальный русский текст при отсутствии загрузчика локали; **legacy/stable 1.5.x UI не меняется**. Начальное состояние индикатора по-прежнему использует исходную версию RDC Relay.
- Прежние `RdcUpdateNoticeStrip`, размеры 25px, плавность/тайминги анимации, `ButtonReady`, `VisualPreviewOnly`, проверка опубликованного коммита/manifest SHA и синхронизация `Show/Hide` **не изменены**. RC1 не может начать установку кнопкой обновления. Перевод не инициирует поиск версии, удаление файлов, работу Host, Remote или сетевой запрос.
- `Source/rc1-owner-gui.ps1`: одна точка отображения при смене языка; не меняет статусы, журнал, IPC или версию. Из-за параллельной незакоммиченной работы статусных окон этот hunk необходимо коммитить отдельно от чужих переводов.
- `Source/lang/{ru-RU,en-US}.json`: **три** новых ключа на каждый язык: `update.owner.idleTooltip`, `update.owner.availableAccessible`, `update.owner.availableTooltip`. Они остаются `INTEGRATION_TEST`, не редакторски утверждены.
- `Tests/Check-V16OwnerI18nBindingCoverage.py` расширен: проверяет также реальные обращения индикатора к языковым ключам, равенство словарей и аргументы шаблонов.

## Открытые условия

- Незакоммиченная работа над переводами статусных сообщений и диалогов остаётся вне этого коммита.
- Нужен визуальный обзор индикатора, подсказки и доступности при русской/английской локали на масштабах 100–200%; также системная темная/светлая тема.
- Строки пользовательских сообщений обновления в других ветках/старом установщике не переводились этим изменением; транзакционные операции Setup/Repair/Uninstall всё ещё имеют отдельные release gates.
