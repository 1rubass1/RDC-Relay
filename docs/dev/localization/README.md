# RDC Relay 1.6.0 — каталог текстов и поэтапная локализация

**Статус на 2026-11-18:** ЭТАП 1 — инвентаризация готова; ЭТАП 2 — **360/360 английских черновиков заполнены**, ни один ещё не утверждён, семантическая привязка и UI-аудит продолжаются; ЭТАП 3 — **начата частичная интеграция** переключения языка в Owner GUI/трей; полный перевод экранов и проверка установленной сборки не выполнены. Установленный клиент и дистрибутив не изменялись.

## Зачем это сделано до релизного установщика

Строки сейчас распределены по PowerShell GUI, WinForms/C# Host и трею, обновлениям, RC1 Pilot, будущему релизному установщику и старой оболочке 1.5.x. Замена текста непосредственно в коде перед переводом рискованна: часть строк является машинными идентификаторами Host/GUI, командами, состояниями провайдера и диагностическими метками. **Протокол и системная диагностика не переводятся.**

## Этап 1. Инвентаризация — выполнен

- **Источник:** `STRING_INVENTORY.csv` — один индекс *кандидатов* из исходников в `Source/*.ps1`, `Source/*.cs`, `Installer/*.cs`.
- **Воспроизведение:** `Build-StringInventory.ps1`. Полная пересборка без аргументов записывает каталог; `-Check` только сверяет его с текущими исходниками и не запускает приложение. **На HEAD после изменения исходников трея `-Check` сейчас возвращает `INVENTORY_STALE`** (проверено 2026-11-18). Первоначальный CSV сознательно **не переписывается** по установленной границе задачи; он остаётся историческим индексом кандидатов. Перед runtime-интеграцией требуется отдельная контролируемая синхронизация индекса с исходниками.
- **Охват:** 23 исходных файла; 3 860 вхождений литералов, 2 841 уникальный кандидат с идентификатором `TXT-<хеш>`, исходным путём, номерами строк, числом повторов и предварительным статусом.
- **Предварительная сортировка:** `REVIEW_TRANSLATION` — 390, `REVIEW_ENGLISH_UI` — 87, `PRESERVE_PROTOCOL_OR_TECHNICAL` — 2 364. Это **не** означает, что 477 строк следует без проверки переводить: классификация эвристическая, включая журналы, названия UI, значения списков и фрагменты составных сообщений.
- **Области:** Owner GUI (282), Owner Tray/Host (588), Owner internal (414), shared update notice (28), Release installer draft (127), RC1 Pilot installer (285), legacy GUI (889), legacy installer (181), legacy updater (89).
- Внутренний C# в PowerShell `here-string` сканируется как C#, а не заносится в CSV целиком. Комментарии C# и символьные литералы игнорируются. Новые пароли/ключи/частные абсолютные пути в CSV не выявлены.
- **Предел автоматизации:** индекс перечисляет строковые литералы исходного кода, а не готовые предложения из конкатенаций, интерполяций и динамически сформированного текста. Значение `FragmentOrTemplate=True` требует обязательного ручного уточнения; контекст может зависеть от соседних строк или методов. Существующие языковые ресурсы внешних зависимостей и динамические данные сервиса не входят в каталог. `RDC Relay.cmd`, манифесты, бинарные шейдеры и лицензии не добавлены как UI-строки.

## Этап 3. Интеграция выбора языка — ЧАСТИЧНО В РАБОТЕ

- Два языка: **Русский** и **English**. При первой установке предложить язык по Windows UI; для перехода существующей версии сохранить действующий русский по умолчанию, если настройка языка отсутствует. Пользовательский выбор должен иметь приоритет.
- Добавить настройку языка в доступный интерфейс GUI с понятным отображением обоих названий независимо от текущего языка. Хранить выбор в пользовательских настройках; языковая настройка не является учётными данными Remote.
- Применять язык к окну GUI, трею, меню, окнам подтверждения, уведомлениям, accessibility label и всем экранам установщика/восстановления/удаления. Уже записанные исторические журналы не переписывать и не изменять протокол провайдера. Состояния Host и API остаются инвариантными.
- Выбрать общий формат ресурсов, доступный PowerShell и C# (проектно предпочтительны **UTF-8 JSON** с явными именованными параметрами). Исключить чтение/выполнение переводов как кода, предусмотреть fallback на заведомо доступный русский текст, валидацию файлов и ключей.
- Обновление/смена языка не может останавливать или перезапускать Remote; при необходимости перезапускается только GUI в безопасном режиме, если этот сценарий отдельно проверен.
- Релизный Setup и Portable должны включать оба проверенных комплекта ресурсов, не включать `docs/dev/`. Для локализованного установщика отдельно проверить хранение выбора и отображение ошибок **до** доступности основного GUI.
